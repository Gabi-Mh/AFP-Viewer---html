AFP VIEWER FONT PACK  (1 file = 1 font)
======================================
In the viewer click "Fonts folder" and choose this folder once. The fonts are
saved in your browser and load automatically from then on.

Free equivalents (metric-compatible, so line widths match the original):
  Arial, Helvetica .......... LiberationSans, texgyreheros (Heros), FreeSans
  Arial Narrow ............... texgyreheroscn
  Times New Roman, Times ..... LiberationSerif, texgyretermes, FreeSerif
  Courier New, Courier ....... LiberationMono, texgyrecursor, FreeMono, DejaVuSansMono
  Calibri .................... Carlito          Cambria ........... Caladea
  Verdana, Tahoma ............ DejaVuSans       Georgia ........... DejaVuSerif
  Palatino ................... texgyrepagella   Bookman ........... texgyrebonum
  New Century Schoolbook ..... texgyreschola    Avant Garde ....... texgyreadventor
  Zapf Chancery .............. texgyrechorus    Symbol/bullets .... OpenSymbol

Not included: Arial, Times New Roman, Helvetica, Courier New and other
commercial fonts (they cannot be redistributed). If you own them, add their
.ttf files to this folder; a font whose file name matches the AFP font name
(e.g. Arial.ttf for an AFP font called ARIAL) is used first.

Licenses are in the "licenses" folder (SIL OFL, GUST, DejaVu, GPL + font exception).
